### Задание 1 **(3)**

#### Глоссарий

* **Тип в программировании** — атрибут объекта данных, задающий множество допустимых значений и методы работы с ними.
* **Статическая типизация** — тип объекта данных определяется в момент трансляции программы.
* **Динамическая типизация** — тип объекта данных определяется во время выполнения программы, при создании или присваивании значения.
* **Преобразование типа** — метод, преобразующий значение одного типа в такое же или близкое значение другого типа.
* **Каламбуром типизации** называется ситуация, когда одна ячейка данных рассматривается как две переменные разных типов.
* **Ошибкой согласования типа (type error)** называется использование значения одного типа в контексте другого типа.
* **Неявная типизация** — тип определяется автоматически по тексту программы, без явного указания типа.
* **Явное преобразование типа** — преобразование, которое явно указано в программе вызовом функции или специальной операцией.
* **Неявное преобразование типа** — преобразование, которое явно не записано в программе, но автоматически выполняется транслятором.
* **Сильная типизация** — типизация, при которой язык содержит мало или почти не содержит правил неявного преобразования типов.
* **Слабая типизация** — типизация, при которой язык содержит много правил неявного преобразования типов и допускает каламбуры типизации.

Сильная и слабая типизация — это не строгие взаимоисключающие категории, а качественная характеристика системы типов языка.

### Задание 2 **(3)**

#### Неявные преобразования типов в C++

Основные правила:

1. **При присваивании** значение правого операнда приводится к типу левого операнда.
2. **При передаче аргумента функции** фактический параметр приводится к типу формального параметра.
3. **В условии `if`, `while`, `for` и других ветвлениях/циклах** результат условия приводится к `bool`.
4. Если оператор требует **целое число** (например, сдвиг, остаток от деления или битовая операция), соответствующий операнд приводится к целому типу.
5. Если оператор требует **логическое значение**, операнды приводятся к `bool`.
6. При арифметических операциях и сравнениях:
   - типы, меньшие `int`, сначала продвигаются до `int`;
   - при разных размерах меньший тип приводится к большему;
   - для типов одинаковой длины знаковый тип при соответствующих условиях приводится к беззнаковому;
   - при операции целого и вещественного числа целое приводится к вещественному.
7. **Преобразование в `bool`**: `0` превращается в `false`, любое ненулевое значение — в `true`.
8. **Преобразование из `bool`**: `false` превращается в `0`, `true` — в `1`.
9. **Вещественное в целое**: дробная часть отбрасывается.
10. **Символьные типы** при преобразовании рассматриваются по числовому коду символа (`'a' === 97`).
